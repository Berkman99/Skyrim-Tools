# Skyrim Tools

Tools for modding Skyrim Special Edition. Each tool has its own folder.

| Tool | What it does |
|---|---|
| [NPC Appearance Manager](NPC%20Appearance%20Manager/README.md) | Pick NPC looks from your overhauls with pictures, build one merged mod, and switch the merged overhauls off in Mod Organizer 2. |

Saved versions of each tool are listed under **Tags** (for example `NPC-Appearance-Manager-v1`).
